## AI chat 组件重做 v2：还原度质变（拿原版源码做像素级基准）

**根因**：用户反馈样板与原版差距大。复盘：上一轮是「看 WebFetch 文字描述自己写」，没拿原版精确 CSS 作基准 → 颜色/字号/动效全是自嗨（蓝色 #0064FA 臆造 vs 原版 #a1a1a1 克制灰）。

**破局路径**：
- headless Chrome 被反爬超时（本地网络问题，与 GitHub 443 同症），但 **curl 直通**（平台网络 OK）
- aicss.dev 是 shadcn 风格，每个组件有 registry JSON（`/r/{slug}.json`）含完整 TSX + CSS Module
- 批量 curl 14 个 registry JSON → 提取纯 CSS（3066 行）→ 读懂设计语言

**AICSS 设计语言核心**（全部走 token，与 TDesign 完全不同的克制灰语言）：
- 色：`#1a1a1a` 正文 / `#a1a1a1` 次要 / `#e6e8ec` 边框 / `#fafafa` 浅底 / `#f4f5f7` code 底 / `#0b0d12` 发送黑
- 阴影：`0 0 0 0.5px rgba(0,0,0,0.08), 0 1px 2px rgba(0,0,0,0.05), 0 2px 4px rgba(0,0,0,0.02)`（0.5px hairline + 接触 + 环境）
- 字号：13/18、14/19、12.5 mono/20、12/11/10/9
- 圆角：12 卡片、999 pill、7 小按钮、6 tooltip、5 inline-code
- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)` 几乎所有 transition
- shimmer 文字：`#a1a1a1` 渐变 + `background-clip:text` + `background-size:300%` + 2.25s label-shine

### ai-agent-input 假输入框修复（可交互性第一原则）
用户反馈：「代理输入框的对话框 yuanqi-ai-composer-frame 似乎是假的，不能输入文字，同类型的都检查一下」。

**根因**：`.yuanqi-ai-composer-field` 用 `<div>` + `::before` 假占位符（`data-empty` 属性切换），不是真输入元素，无法聚焦/输入。同类全扫：approval-card 的「其他…」是 `<input>` 真；message-bubble 无输入框（纯气泡展示）；thinking/streaming/text-response 都不含输入。**只有 ai-agent-input 的 4 个 composer-field 是假的**。

**修复**：
1. `<div>` → `<div contenteditable="true" role="textbox" aria-multiline="true">`（4 处：idle / filled / enhanced / attachments）
2. CSS placeholder 选择器 `[data-empty]::before` → `:empty::before`（contenteditable 删空后 Chrome 留 `<br>` 无法用 `:empty`，但初始空态完美）
3. 加 `.yuanqi-ai-composer-field:focus { outline: none; }`（卡片式无 outline 还原 AICSS）
4. filled 态顺手合并 pill 后换行（`</span></span>\n            写...` → 同行）—— contenteditable 下换行会让光标位置错乱

**为什么 contenteditable 而非 textarea**：AICSS 原版就是 contenteditable，因为需要内嵌行内 skill 药丸（`<span class="...-skill-pill">`）。textarea 无法容纳行内元素。

**验证**：puppeteer-core 真输入 `帮我写个登录页` → BEFORE `text:"" empty:true` → AFTER `text:"帮我写个登录页" empty:false`，placeholder 自动隐。filled 态截图 pill 与文本同行，视觉无破坏。

**踩坑**：puppeteer 首次启动偶发 `Target.setAutoAttach timed out`，加 `protocolTimeout: 60000` + `--disable-gpu` 重试即过。
