## 第 37 轮：详情页顶栏标题随正文滚动切换 ✅

**需求**：左栏纵向滚动时，`.td-bar-title`（"任务详情"）文字变为 `.td-title`（任务标题）。

### 实现（只改 `pages/task-detail.html`，+60/-3）
1. **HTML**：`.td-bar-title` 拆成两层子 span —— `.td-bar-title-a`（静态"任务详情"）+ `.td-bar-title-b`（JS 填任务标题，带 `aria-hidden`），容器挂 `data-td-bar-title` 钩子
2. **CSS**：容器 `flex:1 1 auto; min-width:0; display:grid; grid-template-columns:minmax(0,1fr)`，两层 `grid-area:1/1` 叠同格 → `opacity` 交叉淡入 `.2s cubic-bezier(.4,0,.2,1)`；长标题 `ellipsis`；带 `prefers-reduced-motion` 降级
3. **JS**：新增 IIFE `bindScrollTitle()`（紧跟 `bindSwapBar` 调用后），监听 `.td-main` scroll（passive + rAF 合帧），`scrollTop > 8` 切 `.is-scrolled`

### 关键判断（有实测依据）
- **滚动容器**：实测 1440×900 → `.td-main` sh972/ch796 可滚，`.td-side` 796=796 不可滚，`.td-root`/`.td-wrap` overflow visible ⇒ 左栏唯一纵向滚动容器就是 `.td-main`
- **为什么用 grid 叠格而非 `position:absolute`**：absolute 会脱离文档流，影响 `.td-bar` 的 baseline/高度
- **阈值 8px**：避开展开/折叠正文的 1~2px 抖动；阈值内（实测 4px）不切换
- **副作用零**：实测按钮组右缘 = bar 右缘 − 20（padding 保持）、返回钮右=56 → 标题左=64（gap 8 保持）、7 个动作按钮位置不变；初始态截图与改动前逐像素目视一致
- **互换/全屏兼容**：`.is-swapped` 走 CSS row-reverse 不改 DOM 顺序 ⇒ 监听仍成立；全屏态 `.td-left` 隐藏无影响

## 第 37 轮第 2 项：详情页左栏文件图标按设计稿还原 ✅

**需求**：左栏「2个附件 / 3个 AI 产物 / 文件」各分组标题与条目前的图标不对，按 MasterGo 设计稿还原。

### 根因（实测）
实现是**手绘 stroke（描边）近似版**，设计稿是 **fill（填充）风格**——形状与风格均不一致；附件图标盒尺寸 16 也与设计稿 14 不符。

### 关键突破：拿到设计稿精确 SVG（可复用流程）
1. `get_selection_node(targetNodeId="622:13950")` 拉根节点 → 图标全是 `<img src="./asset/icons/svg_xxx.svg">`，**没有 path**
2. 素材已落盘在 Asset Session：`~/.mgmcp/artifacts/blobs/sha256/**`（49 个 SVG），文件名是 sha256，无法直接对应
3. **破局点**：每个 blob 内含 `clipPath id="master_svg0_{nodeId}"` → 用 `grep -l "master_svg0_622_08923"` **精确反查节点↔文件**
4. 清洗：剥 `<defs>/<clipPath>` 包装、`clip-path` 引用；单色图标 `fill="#6B6B6B"` → `fill="currentColor"` 交给既有 CSS 变量（色值与设计稿逐条核对一致：--td-ico-gray #6B6B6B / --td-ico-web #327FCB / --td-ico-md #167AB8 / --td-ico-md-fold #4196D6）；三色 `.md` 徽标 → `class="td-ico-md-body|-fold|-mark is-solid"`
