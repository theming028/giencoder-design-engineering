## Table 右键菜单行选中态 + 删除文字 hover 变红

- 需求 1：右键菜单显示时，所属表格行显示浅蓝选中态背景（复用 `--color-primary-light-1` = #EAF5FF，与 checkbox 选中一致）。
  - 实现：contextmenu JS 加 `setActiveRow()` 追踪当前行，show 时加 `.yuanqi-table-tr-context-active`、hide（Esc/点击外部/滚动/resize）时移除。
  - 坑：`.yuanqi-table-tr-context-active .yuanqi-table-td`（0,2,0）低于 hover 规则 `.yuanqi-table-tr:hover .yuanqi-table-td`（0,3,0，:hover 算 1 类级），导致鼠标停在行上时高亮被 hover 的 fill-1 覆盖。解法：补 `:hover` 并列选择器 `.yuanqi-table-tr-context-active:hover .yuanqi-table-td` 拉平到 0,3,0，且行内 <style> 后于 components.css 故胜出。
- 需求 2：操作列删除文字默认不红，hover 才红。
  - `components.css` `.yuanqi-btn-danger-text`：`color: danger-6` → `color: primary-6`，新增 `.yuanqi-btn-danger-text:hover { color: danger-6 }`。全局生效（table/list/ui_kits list-page 共用）。
  - 同步契约：table.json contextmenu 补「菜单打开所属行高亮 primary-light-1」；button.json interaction.hover 补 danger-text 默认主色/hover 转红。

- 教训：puppeteer 测 CSS :hover 必须用 `page.mouse.move`/`page.hover()` 真实移动鼠标，`dispatchEvent(mouseover)` 不触发 :hover 伪类。
