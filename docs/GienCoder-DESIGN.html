1Overview · 四项核心价值

Clear / Consistent / Rhythmic / Open —— 每项都给出对 AI 生成页面的可执行约束。

CLEAR
清晰

信息层级一目了然：标题→正文→说明四级文字；状态用色语义化；表头/行/选中态对比度达标。不堆叠装饰。

CONSISTENT
一致

组件只认 giencoder-* 官方 class 与 Token；同一颜色、圆角、间距、动效全站统一；禁止混用旧 class 或臆造变体。

RHYTHMIC
节奏

间距严格走 2px/8px 体系（--spacing-*），区块间距 16–24px；24 栏栅格；空白有规律、可预见。

OPEN
开放

组件支持代理/扩展，可组合成六大页面模式；扩展不破坏既有契约，鼓励组合而非发明。

⚡ 语义优先硬规则：颜色一律先查语义层（bg / text / border / fill）→ 再退功能色/色阶 → 最后才允许直接引用基础色板（仅图表、品牌场景）。禁止硬编码 hex。
