## 能力边界（超出编译器，待补）

1. **`tree` emitter**（树形表格）—— 契约有，实现缺。本页最大还原度缺口。
2. **动态筛选/搜索/状态聚合** ——编译期无逻辑引擎，需 JS 状态层。
3. **`chart`** 与 Toast —— 契约有 chart 但 emitter 待补；Toast 无 emitter。

## 建议下一步

## 高保真还原（第 2 轮新增）

用户反馈 DSL 版还原度低。应对：**把原型成品（已过验收的完整单页）收编为 giencoder 自包含金标**，可运行交互 100% 保留。

| 项 | 内容 |
| :-- | :-- |
| **产物** | `giencoder/task-list-self-contained.html`（79KB，CSS+JS 全内联，零外部依赖） |
| **预览** | `http://127.0.0.1:8799/task-list-self-contained.html` |
| **QA** | preview-audit → **0 阻断 0 P1**，截图 1440×1000=198KB（渲染完整） |

**保留的完整交互**：树形 L1/L2 展开折叠、聚合统计条实时刷新（PRD 第7章算法）、四维筛选+全局搜索+活动标签、创建/新增/删除/分配弹窗、指标下钻+同步异常双抽屉、行内状态流转（开始/停止/完成/取消/重试）、Toast 反馈、导航计数、通知 badge。

**Token 化改造**：去 Google Fonts → 系统字体栈；CSS/JS 全内联（自包含）；legend 状态色改为语义 `var(--color-*)`。

**同步修了 preview-audit.py 三个验证缺陷**：
1. **PageParser 不跳过 `<script>/<style>`** → 内联 JS 模板字符串被误当标签 → 自包含页必然误报标签失衡。已加 `_script_style_depth` 跳过高保真内联脚本。
2. **primary CTA 正则不识别带 id 的 `btn-primary`** → 误报 unclear_primary_task。改为宽松 `\bbtn-primary\b` 类匹配。
3. 插入 aria-label 时顺带修正了一处标签未闭合的格式问题。

## 高保真 vs DSL 路径定位

- **DSL 编译版**（`dsl/output/task-list.html`）：受控生成的**架构骨架**，证明管线可用，但交互为静态。
- **自包含金标**（`task-list-self-contained.html`）：**高保真可运行产物**，用于走查与效果确认。
- 两版已对齐「无外部依赖、可离线打开、QA 通过」的门禁。
