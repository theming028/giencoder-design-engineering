Link 链接

源启链接：默认链接（弧蓝 #3770F7 下划线，hover 加深）、带图标链接、禁用链接与状态色链接，用于页面内跳转与操作入口。

Default 默认链接
默认色 --color-link-6（#3770F7）带下划线；hover 加深为 --color-link-hover（#6692F9），transition 时长 0.1s。

Icon 带图标链接
前缀内联 SVG 图标（stroke="currentColor" 随链接取色），图标与文字间距 4px；hover 同样加深并保持下划线。

Disabled 禁用链接
颜色灰化为 --color-text-4，去除下划线，cursor:not-allowed 且 pointer-events:none 不可点击。
禁用的链接 — 不可点击、不可聚焦，用于无权限或无可用操作的场景
Status 状态色链接
status 语义色：success / warning / danger，用于表内操作列与结果反馈。
