Affix 固钉

源启固钉：滚动容器内嵌固定条（offsetTop 模拟），吸附于顶部时白底 + 阴影始终可见。

Affixed 滚动容器内固定在顶部（position: sticky 模拟 offsetTop）
筛选条件 · 快捷操作工具栏

该容器模拟页面滚动区域。滚动容器时，上方工具栏会吸附在容器顶部（position: sticky + top: 0 模拟 Affix 的 offsetTop 阈值），始终保持可见。

1. 设置 offsetTop 阈值：滚动位置超过阈值后固钉生效；

2. 容器内嵌固钉：工具栏不随内容滚出可视区，方便随时操作；

3. 吸附样式：白底（--color-bg-2）+ 底边 1px 硬线（box-shadow: inset 0 -1px 0 模拟，--color-border-1），与页面内容清晰分层。

下方为占位说明文字，用于撑起可滚动区域，验证固钉吸附效果。可继续添加更多内容以观察滚动行为。

在实际业务中，固钉常用于长表单的提交栏、列表页的筛选区、详情页的页签工具条等高频操作场景。

Static 未达到 offsetTop（固钉不生效，条随内容滚动）

滚动前（未达到 offsetTop 阈值）固钉不吸附，工具条位于内容流中，随内容一同滚动。

1. 该状态对应 Affix 的 affixed=false：条处于文档流普通位置；

2. 一旦滚动位置越过阈值，工具条切换为 fixed 吸附态；

3. 开发者可通过 offsetTop 控制触发时机，避免首屏即吸附造成的遮挡。

占位工具条（静态态）

占位说明文字：对比上方"吸附态"示例，本示例中工具条位于内容之后、无粘性定位，滚动时会随内容移出可视区。
