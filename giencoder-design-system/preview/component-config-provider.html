ConfigProvider 全局配置

源启全局配置：在应用根节点统一配置主题、语言、组件前缀等，无视觉交互，纯说明展示。

Capabilities 核心能力
主题切换 Theme
通过 theme 在亮色 / 暗色主题间全局切换，基于 Design Token 一键换肤。
语言 locale
通过 locale 内置 zh-CN / en-US 等语言包，全局统一组件内置文案。
组件前缀 componentPrefix
通过 componentPrefix 自定义组件 DOM class 前缀，适配宿主应用规范，避免样式冲突。
聚焦样式 focusLock
通过 focusLock 统一配置弹层 / 组件的聚焦表现，支持将焦点锁定在弹层范围内。
渲染空状态 renderEmpty
通过 renderEmpty 全局自定义无数据时的空状态组件，保持各场景展示一致。
Integration 包裹示意
<ConfigProvider> 包裹应用根节点，所有子组件共享全局配置
