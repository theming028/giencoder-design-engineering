Tag 标签

源启标签：默认/描边/亮色/暗色变体，状态色、可关闭、可选中。映射自既有状态标签（文字/面/描边 3 变体）。

Default 默认标签
默认 主色标签 成功 警告 危险 禁用
Outline 描边标签（对应既有"描边"变体）
描边 主色描边 成功描边 危险描边
Light 亮色标签（对应既有"面"变体）
亮色 主色亮底 成功亮底 警告亮底 危险亮底
Status 状态点标签（对应既有"文字"变体）
运行中 待处理 已停止 已归档
Closable 可关闭标签
可关闭 完成
Checkable 可选中标签
