VerificationCode 验证码输入

源启验证码输入：6 位 40×40 方框，2px 边框 --color-border-2、4px 圆角，当前输入位聚焦 --color-primary-6 边框 + 光标。

Default 输入中（前 3 位已填 123，第 4 位聚焦 + 光标）
1 2 3
Completed 已完成（6 位全部填写）
1 2 3 4 5 6
Error 校验失败（--color-danger-6 边框）
1 2 3
验证码错误，请重新输入
