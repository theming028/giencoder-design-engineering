# 无障碍规范（Accessibility）

> 层级：L5 ｜ 依据：WCAG 2.1 AA ｜ 适用范围：所有 源启组件与页面
> 每个组件的具体 ARIA 要求见 `components/{slug}.json` 的 `a11y` 字段，本文档定义全局规则。

---

## 1. 色彩与对比度

| 规则 | 要求 |
|------|------|
| 正文/图标 | 与背景对比度 ≥ 4.5:1（AA） |
| 大字号（≥24px）或粗体（≥19px） | ≥ 3:1 |
| 组件边界/输入框边框 | ≥ 3:1（非文本对比度 1.4.11） |
| 焦点指示 | 可见焦点环，对比度 ≥ 3:1，不依赖单一颜色 |

**参考值**：`--color-text-1`(#1F1F1F) 在 `--color-bg-1`(#FFF) 上对比度 ≈ 15:1 ✅；`--color-text-2`(#4E4E4E) ≈ 6.8:1 ✅；`--color-text-3`(#868686) ≈ 3.7:1 ⚠️（仅限次要信息）；`--color-text-4`(#C9C9C9) ≈ 2:1 ❌（禁用态，豁免）。

## 2. 键盘可访问性

| 组件类 | 键盘行为 |
|--------|---------|
| 按钮/链接/开关 | Tab 聚焦，Enter/Space 触发 |
| 表单控件 | Tab 流转，Space 切换（Checkbox/Switch），方向键（Radio/Slider/Select） |
| 弹层（Modal/Drawer/Select/Dropdown） | 打开时焦点移入，Tab 循环（focus trap），Esc 关闭并归还焦点 |
| 菜单/Tabs/Tree | roving tabindex，方向键导航，Home/End 首末 |

**焦点可见**：`:focus-visible` 焦点环不得移除；自定义样式须提供等效可见指示。

## 3. ARIA 语义

| 组件 | Role | 关键 ARIA |
|------|------|-----------|
| Button | `button` | `aria-disabled`（禁用）、`aria-busy`（loading）、`aria-label`（纯图标） |
| Input | `textbox` | `aria-invalid`（校验失败）、`aria-describedby`（错误/帮助文本） |
| Checkbox | `checkbox` | `aria-checked`、`aria-disabled` |
| Radio | `radio` | `aria-checked`，组容器 `role=radiogroup` |
| Switch | `switch` | `aria-checked` |
| Select | `combobox` | `aria-expanded`、`aria-controls`、`aria-activedescendant` |
| Modal | `dialog` | `aria-modal=true`、`aria-labelledby`（标题）、`aria-describedby`（内容） |
| Drawer | `dialog` | 同上 |
| Tabs | `tablist`/`tab`/`tabpanel` | `aria-selected`、`aria-controls`、`tabindex` 管理 |
| Menu | `menu`/`menuitem` | `aria-selected`、`aria-expanded` |
| Tooltip/Popover | — | `aria-describedby` 关联触发元素 |
| Table | `table`/`grid` | `aria-sort`（排序列）、行/列标题语义 |
| Alert | `alert`（自动读屏播报） | — |
| Spin | — | `aria-busy` + `role=status`/`role=progressbar` |
| Icon | — | 装饰性 `aria-hidden=true`；信息性提供 `aria-label` |

## 4. 焦点管理

1. **弹层打开**：焦点移到弹层第一个可聚焦元素（或安全策略：移到面板本身）
2. **弹层内**：Tab/Shift+Tab 循环，不逃逸到背景页面（Modal/Drawer 必做 focus trap）
3. **关闭**：焦点归还触发元素（保存用户操作上下文）
4. **动态内容**：新增内容需 `aria-live` 或主动移焦
5. **导航切换**：路由跳转后焦点移到页面标题（h1）

## 5. 语义化结构

- 页面骨架用语义标签：`header/nav/main/aside/footer`
- 标题层级 h1→h6 不跳级
- 表单 label 与控件显式关联（`for`/`id` 或包裹）
- 列表用 `ul/ol/li`，表格用 `table` 语义

## 6. 动效安全

- 所有动效时长 ≤ 0.5s（组件默认已满足）
- 闪烁/移动元素不得 >3 次/秒（3 秒内）（1.4.2）
- 尊重 `prefers-reduced-motion`：用户要求减少动效时关闭非必要动画

## 7. 检测清单（生成页面后逐项自查）

- [ ] 纯图标按钮有 aria-label
- [ ] 表单错误有 aria-invalid + 错误文本关联
- [ ] Modal/Drawer 有标题关联且 Esc 可关闭
- [ ] 所有可交互元素 Tab 可达且焦点可见
- [ ] 颜色对比度达标（正文 4.5:1）
- [ ] 装饰性图标 aria-hidden
- [ ] 空/错/载状态对读屏器可感知（role=status/alert）
