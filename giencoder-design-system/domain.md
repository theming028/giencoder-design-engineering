# domain.md — 领域规则

> GienCoder Design System 的业务领域语义层。
> 定义不同业务场景下的色彩映射、数据安全、组件语义规则。

## 色彩领域映射

| 业务语义 | 设计 token | 色值 | 使用场景 |
|---|---|---|---|
| 正常进行中 | `var(--color-primary-6)` | #3770F7 | 选中态、主 CTA、焦点环 |
| 成功 | `var(--color-success-6)` | rgb(green-6) | 完成状态 Badge |
| 失败/高危 | `var(--color-danger-6)` | rgb(red-6) | 错误提示、危险操作 |
| 警告/超时 | `var(--color-warning-6)` | rgb(orange-6) | 超时提示 |
| 中性/禁用 | `var(--color-text-4)` | rgb(gray-4) | 不可操作、占位文字 |

## 组件语义边界

| 信息类型 | 组件 | 说明 |
|---|---|---|
| 任务运行状态 | Badge | 排队/运行中/完成/失败/超时 |
| 风险等级 | Badge + danger 色 | 高危/可疑/低风险 |
| 资源类型 | Tag | ECS/RDS/SLB |
| 业务分类 | Tag | 生产/测试/开发 |
| 行内操作 | Button / Link | 查看/重试/取消 |
| 确认中断 | Dialog | 删除/停止等需确认操作 |
| 复杂详情 | Drawer | 日志查看、配置详情 |

**易混边界**：
- Badge 表达**状态/计数/风险**，Tag 表达**分类/类型/环境**
- Drawer 承载**复杂详情**，Dialog 承载**需确认的中断动作**
- Button 用于**操作**，Link 用于**导航**

## 数据安全

- AccessKey、账号、主机 IP 默认脱敏
- 查看明文需要显式点击
- 明文查看行为需要记录审计日志
- 敏感字段在列表中用 `*` 遮罩，详情页需权限验证后展示

## AI 生成内容

- AI 生成内容必须标注"内容由 AI 生成，请核实重要信息"
- AI 操作入口需有明确的取消/撤销路径
- 自动化任务执行前需确认，执行后需通知
- Agent 调度状态实时可见，失败可恢复

## GienCoder 特定规则

- 工作空间切换不影响当前会话上下文
- 权限选择（默认/完全访问）影响 Agent 可访问的文件范围
- 技能调用通过 `/` 触发，文件引用通过 `@` 触发
- 会话历史按工作目录分组，支持置顶
