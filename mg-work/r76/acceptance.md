## 5. 需求 4 · 技能选择浮窗不再被 header 挡住

### 5.1 根因（实测，非推断）

浮窗按内联规则挂在输入卡正上方；卡顶 = `0.5vh − 62px` ⇒
**可用高 = `0.5vh − 118px`**（**与视口宽无关**，1440/1280/1024 三档同值）。
视口高 < 约 **880** 时该值小于浮窗自身 320px ⇒ 上缘冲出 main 顶，
被「白卡 / main / 根容器」三层 `overflow: hidden` 裁掉
（实测溢出 **77.3px @720**、**157.3px @560**）。

### 5.2 修法

```css
[role="listbox"][aria-label="技能选择"][style*="position: absolute"] {
  max-height: calc(50vh - 120px);
}
```

只夹 `max-height`：内联规则给的是 `height`，`max-height` 天然可压过它；被压掉的高度由浮窗内**既有**的可滚动列表承载。纯声明式 ⇒ 窗口缩放自动跟随，不与 React 的内联样式打架。

### 5.3 四档实测（每档**全新开页**，避免 Esc 复位污染状态）

| 视口 | pop.h | `max-height` 计算值 | 期望 `50vh − 120` | `over = main.t − pop.t` | over ≤ 0 | 列表可滚 (client/scroll) | 进场动效 |
|---|---|---|---|---|---|---|---|
| 1440×900 | 320（自然） | 330px | 330 | −12.8 | ✅ | 否（无需） | `r74-pop-in@160` |
| 1440×720 | 240 | 240px | 240 | **−2.8** | ✅ | 是 194/250 | `r74-pop-in@160` |
| 1440×640 | 200 | 200px | 200 | **−2.8** | ✅ | 是 154/250 | `r74-pop-in@160` |
| 1440×560 | 160 | 160px | 160 | **−2.8** | ✅ | 是 114/250 | `r74-pop-in@160` |

> 改前对照：`over = +77.3 @720`、`+157.3 @560`（= 被裁）。`overlapHeader` 同为 `−2.8` ⇒ 与 header 不重叠。
> 自然档（900）`pop.h = 320`、`max-height 330` 不生效 ⇒ **原样**。

### 5.4 r76d / r76e · 压扁态的「半行」

`max-height` 生效后列表转为可滚，内容在半行处被切断；浮窗底是 `rgba(255,255,255,0.88)` + `backdrop-filter: blur(10px)`，那半行文字**透出来像是"串"到下方按钮条上**。

修法：给 `.skill-pop-list` 加底部渐隐 mask，**只在 `max-height` 真正生效的区间启用**（门槛 = `50vh − 120 < 320 ⇒ vh < 880`，故用 `@media (max-height: 879px)`）。

- 渐隐长 30px 时同一位置仍留约 66% 不透明度、\"串\"感仍在 ⇒ **r76e 加长到 52px**（同位置降到约 35%；末行完整技能文字区仍保 ≥0.94）。
- 范围：选择器带 `[aria-label="技能选择"]` 祖先 —— 该浮窗**只在 base.html 渲染**（其余 8 页虽有 `.skill-pop-list` 的 CSS 拷贝，但无此 aria 节点）⇒ 不波及其他页。
- **零影响现证**：1440×900 档 `getComputedStyle(.skill-pop-list).maskImage === "none"`；720 档 = `linear-gradient(rgb(0, 0, 0) calc(100% - 52px), rgba(0, 0, 0, 0) 100%)`。

## 6. 需求 5 · td-right 收起后不再回弹

### 6.1 根因（改前实测）

1440 视口（**非 keep-left**）收起时：预览栏 `1024 → 0` 走满 200ms，但左栏全程 `display: none`、**腾出的空间无人接收** —— 会话栏一直钉在行的最左（`8..408`，宽 400）。React 摘掉 `.is-browse` 那一帧，**会话栏 `8..408 → 952..1432`、宽度 `400 → 480`、左栏 `0 → 936` 三件事一起硬跳** ⇒ 观感 =「关完之后会话栏猛地弹回右边」。
（r74 只修了 `.is-keep-left` 那一支：门槛 = 行宽 ≥ 约 1609 ⇒ ≈视口 1625px。）

### 6.2 修法（`<style id="r76-td-css">`）

1. 收起期间让左栏 `display: flex; flex: 1 1 0px; min-width: 0; max-width: none; margin-right: var(--td-gap)` 出场，从 0 长到 936 **吸收预览栏腾出的空间**（`basis: 0` ⇒ 起始帧不占位，与改前同一起点）。
2. 收起期间把会话栏宽度提前切到普通态值（浏览态 400 → 普通态 480）并补一条同长过渡。
3. 两条都只在 `:has(> .td-browse-slot > .td-browse.is-closing)` 命中 ⇒ **只影响「收起」**；减动画偏好下过渡关闭、退化为瞬时（与全站一致）。

### 6.3 逐帧（展开 → 稳定 700ms → 收起，rAF 逐帧）

**1440×900（主分支）**

```

t= 41  b=1 pc=1  rL= 729.30  rR=1190.42  rW=461.13  sW= 241.58  lW= 713.30
t= 92  b=1 pc=1  rL= 915.41  rR=1392.30  rW=476.89  sW=  39.70  lW= 899.41
t=141  b=1 pc=1  rL= 949.08  rR=1428.83  rW=479.75  sW=   3.17  lW= 933.08
t=192  b=1 pc=1  rL= 952.00  rR=1432.00  rW=480.00  sW=   0.00  lW= 936.00
t=242  b=0 pc=0  rL= 952.00  rR=1432.00  rW=480.00  sW=   0.00  lW= 936.00   ← React 摘类
```

- `rL` **全程单调不减**（`max 反向步 = 0`）；`rW 400 → 461.13 → 476.89 → 479.75 → 480`；`sW 1014 → … → 0`；`lW 2 → 713.30 → … → 936`
- **摘类那一帧（t≈242，`b 1→0`）所有几何与前一帧逐位相同** ⇒ 回弹消除 ✅
- 静止态 `rL 952 / rR 1432 / rW 480 / lW 936` 与普通态逐位重合

**1920×1080（keep-left 分支，r74 已有修法）**：`rL 616 → 1097.02 → 1376.77 → 1427.58 → 1432`，同样单调；`rW` 恒 480、`sW 816→0`、`lW 600→1416`；摘类帧零变化 ⇒ **r74 分支未受影响**。
