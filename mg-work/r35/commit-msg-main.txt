- 样式层：av-* 为视图适配层，一律作用在 DS 契约类（.giencoder-card / -card-header /
  -card-header-title / -card-header-extra / -card-body / -avatar / -tag / -btn）之上，
  不改组件本体；颜色/圆角/字号全部走 token，两处非 token 色（#6B6B6B / #A9A9A9）
  收敛为 --av-ink-2 / --av-ink-4 局部变量。
