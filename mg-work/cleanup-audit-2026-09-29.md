## 〇、结论先行（第一性原理）

**这个仓库里几乎没有"系统垃圾"。** 无效文件、临时文件加起来只有 **38 KB**：

| 类别 | 数量 | 体积 |
|---|---|---|
| `.DS_Store`（macOS 系统垃圾） | 4 | 38 KB |
| 零字节 `.log`（抓取失败残留） | 3 | 0 B |

真正占地方的是三块：
```
工作区 140.9 MB / 2920 文件       ·  .git 111 MB  →  合计 259 MB
├─ mg-work  133.2 MB   取证资产（PNG 900 张 = 101 MB）
├─ pages      4.2 MB   9 个页面（生产内容）
└─ 其他       3.5 MB   assets / DS / docs / .workbuddy
```

### ★ 决定性事实：删工作区文件 ≠ 省磁盘

所有 2918 个受控文件**都已入库**（`git status` 干净）。从工作区删掉一个文件，它的 blob 仍躺在 `.git` 里被历史引用，**磁盘占用几乎不变**。

同时 `.git` 里现况异常：**72 MB 是未打包的 loose objects**（`git count-objects` 实测），完全没被压缩。

⇒ 真正能立刻见效的，是 **`git gc`**（零风险、不删任何文件），而不是删资料。
