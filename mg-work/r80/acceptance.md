## 6. 三处**有意**偏差（都不是漏改）

1. **触发器 logo** = `#3491FA` + 白「P」—— 设计稿直给，**不是**某个空间的 logo。
2. **7 个 logo 色是设计稿的新配色** —— 与基础工作台现有 7 色（`#9E67E1…#F49250`）**完全不同**
   ⇒ 设计稿是「新配色占位」，不是「复制基础工作台浮窗」。
3. **浮窗右缘对齐触发器右缘**（`left = trig.right − 388`）—— 基础工作台是**左对齐**（其触发器在左簇）；
   挪到右上角后沿用左对齐会**右溢出视口**。

## 7. 已知取舍

- 浮窗 7 条**文案是占位**（沿用现有 7 个工作空间名 + 副标题）。换真实文案只需改 `apply80.py` 的 `SPACES` 数组。
- 面板底/描边用 **CSS**（`border` + `box-shadow`）而非设计稿的 `svg_91ab8c7e.svg` 图片：
  视觉等价（`1px #E5E5E5` + radius8 + `0 8px 20px rgba(0,0,0,.1)`），但**可自适应高度**，
  矮视口能靠 `max-height` + 列表滚动优雅夹取。
- 条目选中态用 `box-shadow: inset 0 0 0 1px #D3E2FF` 而非真 `border`：
  设计稿把描边画在独立背景层上，用真边框会让内部绝对定位元素整体偏 1px（详见 PLAYBOOK P3.12 ⑥）。
