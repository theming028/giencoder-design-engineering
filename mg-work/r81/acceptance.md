## 6. 有意偏差与取舍

1. **触发器宽度 254 而不是设计稿的 251**（+3px）。差在字体度量：名称「PAA团队工作空间」在本机字体下的实测宽度与设计稿导出略有出入，未做人为压缩。触发器的 padding / gap / 内部件尺寸均按设计稿。
2. **浮窗 `max-height` 用 `calc(100vh - 48px)`，而非基础工作台的 `480`**。基础工作台的 React 源码写死 `maxHeight:480`，会把设计稿的 526 截掉；本轮以设计稿尺寸为准，同时保留越界兜底（上方够位时自动翻到触发器上方）。
3. **触发器不复用 `.ws-trigger-hover`**。该类的 hover 色 `#E4E6EA` 是为基础工作台顶栏底色 `#F4F5F6` 配的；研发工作台顶栏是 `#E5EDF5`，设计侧给定 `#DAE3ED`。复用会得到错误颜色，故自建 `.r81-ws-trigger:hover`。列表项 hover（`.ws-item-hover`）与搜索框 placeholder（`.ws-search-input`）仍在白色浮窗内，底色相同，**照旧复用**。
4. **7 条列表文案仍是占位**（沿用现有工作空间名 + 副标题）。设计稿里 14 个 `text/title` 实例全部 `props="{}"`，取不到文字。真名给出后只需改 `apply81.py` 里的 `SPACES` 数组（7 行），4 页一键同步。
5. **上一轮的 3 处偏差中，已按本轮指示消解第 3 条**（r80 的「浮窗右缘对齐」→ 现改回与基础工作台一致的左对齐）。剩余 2 条仍待确认：① 触发器 logo `#3491FA` + 白「P」；② 7 色为设计稿新配色（≠ 基础工作台现有 7 色）。

## 7. 已知取舍（非本轮引入）

- 顶栏左簇是 `w-60`（240px 定宽），触发器到位后左簇内容宽约 52+20+254 = 326px，溢出到右侧空白区（页签从 626px 起），不遮挡任何交互元素，也不产生横向滚动条。
- `dev.html` 左簇里被 `opacity:0 / pointer-events:none` 隐藏的外壳容器仍占位（宽 213px），位置在新触发器之后；其余 3 页该容器塌陷为 0×0。两种情况都不影响触发器坐标（实测 4 页 x 均为 88）。
